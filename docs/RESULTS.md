# 구현 결과

MGeo link/node 데이터를 바탕으로 구성한 도로망과 링크 기반 주행 정보 생성 결과를 정리했다.

## 도로망 구성

| 항목 | 결과 |
| --- | ---: |
| MGeo link | 634개 |
| MGeo node | 480개 |
| 전체 검색용 선분 | 74,782개 |
| 순환 route | 40개 항목, 39개 고유 link |
| route 중심선 길이 | 약 2,184.612m |
| route와 주변 차로를 포함한 검색 범위 | 55개 link |
| 현재 link 검색용 선분 | 7,560개 |

MGeo 로컬 좌표를 UTM 좌표로 변환하고, node 연결 관계와 좌우 차선변경 관계를 그래프로 구성했다. 순환 route와 최대 3회 차선변경으로 연결되는 link를 현재 위치 검색 범위로 사용했다.

## 주행 후보와 후방 목표

39개 고유 route link의 원본 point 배열 중간 지점을 표본으로 선정해 기하 계산 결과를 확인했다.

| 생성 결과 | 표본 검사 결과 |
| --- | ---: |
| center 후보 | 39개 |
| left 후보 | 4개 |
| right 후보 | 6개 |
| 기본 8m 후방 목표 | 39개 |

후보는 현재 차로 유지와 좌우 Bezier 차선변경 경로로 구성되며, 목적 link 중심선을 함께 제공한다. 후방 목표는 이전 link 연결 관계를 따라 위치와 yaw를 계산한다.

## 현재 link 전환과 도로 문맥

새로운 link가 기본 10회 연속 관측될 때 현재 link를 전환하도록 구성했다. 확인 중에는 기존 link에 차량을 투영해 진행도와 후보 경로의 연속성을 유지한다.

현재 link와 종료 node를 결합해 제한속도, 정지선, 신호등 ID, 진행 신호와 구간 label을 생성한다. 지정 신호 link에는 다음 preview 거리를 적용했다.

| Link | 신호 유형 활성 범위 |
| --- | ---: |
| `A2256W000213` | 종점 전 25m |
| `A2256W000308` | 종점 전 20m |
| `A2256W000315` | 종점 전 20m |

회전교차로, 고속도로 진입, 차로 번호, 톨게이트와 가드레일 종점은 link별 label로 표현했다.

## 가상 중앙선

link 중심선을 왼쪽으로 1.15m 이동해 가상 경계를 생성했다. `A2256W000304 → A2256W000148` 구간은 접속점 중복 제거 후 502개 point의 연속 경계로 구성되었다. `A2256W000213`에도 동일한 offset 기준을 적용했다.

## 동적 객체의 도로 기준 표현

이동 상태와 진행 방향이 유효한 객체를 대상으로 자차 거리와 link heading 조건을 적용하고, 다음 결과를 생성하도록 구현했다.

- 객체 추적 ID와 최근접 link ID
- link 중심선 위 UTM 투영점
- 자차와 객체 사이 평면거리
- link 중심선 기준 좌우 부호를 가진 횡거리
- link와 객체의 진행 방향 차이
